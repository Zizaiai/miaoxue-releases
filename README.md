# 喵学

把收藏变成自己的学习笔记。此仓库用于发布喵学的 Mac 安装包与更新清单。

**[下载最新版喵学（Apple 芯片 Mac）](https://github.com/Zizaiai/miaoxue-releases/releases/latest)**

## 安装和更新

1. 在发布页下载安装包，打开 DMG 后将「喵学」拖入「应用程序」。
2. 已有旧版时，先保存笔记并退出，再替换同名应用。正常替换会保留独立资料目录里的收藏、笔记和平台会话。
3. 0.3.0 及更早版本需先手动安装一次 0.4.0；之后可在「设置 → 检查更新」查看新版，也可开启自动检查。下载和替换由使用者决定。

目前适用于 Apple 芯片 Mac（macOS 12 或更高），尚未完成 Apple Developer ID 签名和公证。Intel Mac、Windows、手机分享扩展与 iCloud 自动同步尚未提供。

## 你的资料在哪里

无需注册喵学账号。收藏、笔记和平台会话保存在使用者自己的电脑；开发者没有接收这些资料的后台。

检查更新会访问 GitHub 公开文件，GitHub 会收到普通网络请求信息，例如 IP 地址。自动检查可在设置中关闭。更新清单经过发布者签名，安装包下载后会校验完整性。

发布页的 update.json 供应用自动读取，无需手动打开。
